## מה הכלי עושה

כלי למרצות ולמרצים בהשכלה הגבוהה:

1. **מיומנות וקורס** – מזינים מיומנות שרוצים לפתח (למשל חשיבה ביקורתית) ואת הקורס או התחום.
2. **תת-מיומנויות** – הכלי מציע 3–5 תת-מיומנויות, ובוחרים אחת.
3. **כלים** – הכלי מציע 2–4 כלים (מודלים ושגרות קצרות) לפיתוח תת-המיומנות.
4. **העמקה** – הסבר מורחב על כלי ומקורות לבדיקה.

הכלי פועל בעברית ובאנגלית. אין בו חיפוש ברשת: קישורים מגיעים מהידע של Claude ומסומנים "לא מאומת", ולצד כל מקור יש קישור חיפוש לבדיקה.

## What it does

A tool for higher-education instructors: enter a skill and a course, choose one of 3–5 suggested sub-skills, get 2–4 tools to teach it, and open a deep dive on any tool. Hebrew and English. No live web search: links come from Claude's knowledge and are marked "unverified", with a search link beside each source.

## על מה הוא מבוסס | Based on

- Tifferet, S. – Conceptual Model of Skills (core skills, intermediate skills, tools)
- Tifferet, S. – Guidance for breaking a skill into sub-skills
- Reference examples: NACA Employability Skills Assessment; OECD Competency Framework (2014); ESCO v1.2 transversal skills (European Commission); O\*NET Content Model (National Center for O\*NET Development); Hosseinioun, Neffke, Zhang & Youn (2025), *Nature Human Behaviour*, 9(4), 673–687.
